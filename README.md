# QQ 自动回复脚本

一个基于 Python + PyAutoGUI 的 QQ 消息自动回复脚本。当检测到 QQ 消息图标闪烁时，自动打开聊天窗口、输入回复并发送，最后关闭窗口。

## 功能特点

- 通过屏幕截图模板识别 QQ 消息图标、输入框、发送按钮
- 自动输入预设回复并发送
- 语音播报关键状态（可选，依赖 `pyttsx3`）
- 支持自定义监听屏幕区域，提升识别速度
- 支持 `Ctrl+C` 或鼠标移到屏幕左上角安全停止

## 文件说明

| 文件 | 说明 |
|------|------|
| `qq_auto_reply.py` | 主程序 |
| `requirements.txt` | Python 依赖 |
| `assets/qq_icon.png` | QQ 消息提醒图标截图（需自备） |
| `assets/input_area.png` | 聊天窗口输入框截图（需自备） |
| `assets/send_btn.png` | 聊天窗口发送按钮截图（需自备） |

## 安装依赖

```bash
pip install -r requirements.txt
```

如果只用自动回复不需要语音，可以不装 `pyttsx3`：

```bash
pip install pyautogui opencv-python
```

## 截图准备

脚本依靠 **模板匹配** 识别屏幕元素，所以你需要截取自己电脑上 QQ 的对应元素。

### 推荐截图工具

按 `Win + Shift + S` 打开系统截图，或直接用 QQ 截图。

### 三张必备截图

1. **assets/qq_icon.png**
   - 截取任务栏上闪烁的 QQ 消息图标（比如有人发消息时头像会闪动）
   - 建议只截取图标本身，周围留少量空白即可

2. **assets/input_area.png**
   - 打开一个 QQ 聊天窗口，截取输入框区域
   - 建议包含输入框和边缘，避免背景太复杂

3. **assets/send_btn.png**
   - 截取聊天窗口右下角的“发送”按钮
   - 只截按钮本身更容易识别

### 截图小贴士

- 图片格式用 **PNG**（保留像素细节）。
- 截图尽量和运行时 QQ 窗口大小一致，因为缩放后可能匹配失败。
- 如果匹配不到，可以降低 `confidence` 值（比如 0.75 或 0.7），但太低会误识别。

## 配置脚本

打开 `qq_auto_reply.py`，修改 `CONFIG` 中的参数：

```python
CONFIG = {
    "screen_region": (0, 0, 2560, 1600),  # 监听区域：x, y, width, height
    "confidence": 0.8,                    # 匹配置信度
    "auto_reply": "您好，我现在不在电脑前，稍后回复您。",  # 回复内容
    "check_interval": 1,                  # 每秒检测一次
    "click_delay": 0.5,                   # 鼠标移动延迟
}
```

### 关于 `screen_region`

- 设置为 `None`：全屏搜索，速度较慢。
- 指定区域：只在该矩形范围内搜索，速度快很多。
- 格式：`(左上角 x, 左上角 y, 宽度, 高度)`。

例如，你的任务栏在屏幕底部，屏幕分辨率是 2560×1600，可以只监听底部 300 像素高的区域：

```python
"screen_region": (0, 1300, 2560, 300),
```

## 运行

```bash
python qq_auto_reply.py
```

启动后会听到语音播报“QQ 自动回复已启动”，然后脚本开始循环检测。

## 停止脚本

- **方法 1**：在命令行窗口按 `Ctrl+C`。
- **方法 2**：把鼠标快速移动到屏幕左上角（坐标 0,0），PyAutoGUI 会触发安全停止。

## 常见问题

### 1. 提示找不到图标

- 检查 `assets/` 下图片是否存在。
- 降低 `confidence` 到 0.75 或 0.7 再试。
- 确认截图和当前 QQ 界面一致（缩放比例、主题皮肤等）。

### 2. 发送消息失败或发错地方

- 检查 `input_area.png` 和 `send_btn.png` 是否截得准确。
- 增加 `click_delay` 或 `ensure_window_active()` 里的等待时间。

### 3. 语音报错

- 语音只是提示作用，不影响自动回复。如果报错，可以忽略或卸载 `pyttsx3`。
- 也可删除 `init_speaker()` 和 `speak()` 调用。

### 4. 多显示器/高分屏

- PyAutoGUI 在某些高分屏上坐标可能有缩放问题。建议将系统缩放设为 100%，或截图时和运行时使用同一缩放比例。

## 安全提示

⚠️ 本脚本会控制鼠标和键盘。运行前请确保：

- 你已经保存好其他工作。
- 不要让脚本在你看不到屏幕时长期运行，防止误操作。
- 不要把自动回复内容设为敏感或不当信息。
